O Eco Hydro é um projeto desenvolvido no SENAI com o objetivo de reduzir o desperdício de água gerado pelos aparelhos de ar-condicionado. A ideia surgiu a partir da necessidade de encontrar uma solução sustentável para reutilizar a água que normalmente é descartada diariamente.
O sistema realiza a captação dessa água para que ela possa ser reutilizada em atividades como limpeza, irrigação de plantas e outras tarefas que não exigem água potável. O projeto foi pensado para ser simples, acessível e sustentável, incentivando a conscientização ambiental e o uso responsável dos recursos naturais.
O desenvolvimento do projeto envolve tecnologias como HTML, CSS e JavaScript,, além da criação de protótipos e pesquisas voltadas para sustentabilidade e inovação.
O Eco Hydro representa uma iniciativa educacional criada no SENAI para unir tecnologia, sustentabilidade e impacto social, mostrando como pequenas soluções podem gerar grandes mudanças no futuro.
